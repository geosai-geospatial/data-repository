Semua hasil memakai sistem koordinat WGS 84 (EPSG:4326), yang dibaca oleh hampir semua aplikasi GIS dan peta web.

Pernyataan privasi data

GeoSAI tidak menyimpan data yang Anda konversi. Kami membangun alat ini sehingga file Anda memang tidak pernah sampai ke kami:

  • Tidak diunggah.File dibaca dan dikonversi oleh browser di perangkat Anda. Isinya tidak dikirim ke server GeoSAI maupun pihak ketiga; situs ini tidak punya server pengolah data.
  • Tidak disimpan.GeoSAI tidak menyimpan, menyalin, melihat, atau membagikan file Anda maupun hasil konversinya. Data hanya ada di memori tab ini dan hilang saat Anda menekan Hapus data dari memori browser, memuat ulang, atau menutup halaman.
  • Hasil langsung ke perangkat Anda.File hasil dibuat di browser dan langsung diunduh. Tidak ada salinan di tempat lain.
  • Hanya statistik anonim.Kami menghitung kunjungan halaman dan jumlah konversi per format (mis. "shp ke geojson") dengan GoatCounter, tanpa cookie dan tanpa data pribadi. Nama file, isi file, koordinat, dan atribut tidak pernah dicatat.
  • Bisa Anda periksa sendiri.Halaman ini memasang aturan keamanan browser (Content Security Policy) yang hanya mengizinkan koneksi ke situs ini dan penghitung statistik di atas. Anda juga bisa memutus internet setelah halaman terbuka: konversi tetap berjalan.

Anda tetap bertanggung jawab atas hak penggunaan data yang Anda konversi dan atas file hasil yang tersimpan di perangkat Anda.

Batas ukuran file

Di perangkat ini: …

Karena semuanya diolah di browser, file harus muat di memori satu tab. Saat dikonversi, file teks (GeoJSON, KML, CSV) memakan memori sekitar 5–8 kali ukurannya. Browser di komputer memberi satu tab sekitar 4 GB, browser ponsel sekitar 1–1,5 GB. Maka batasnya:

  • Komputer250 MB
  • Komputer dengan RAM 4 GB150 MB
  • Komputer dengan RAM 2 GB atau kurang75 MB
  • Ponsel/tablet dengan RAM 6 GB atau lebih100 MB
  • Ponsel/tablet lain50 MB

Isi .zip/.kmz setelah diekstrak boleh hingga 2× batas. Untuk file yang lebih besar: potong per wilayah, sederhanakan geometrinya (di QGIS: Vector → Geometry Tools → Simplify), atau minta kami mengonversinya.
