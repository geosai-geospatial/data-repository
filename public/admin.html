Admin

Sign in with a GitHub access token that can write to . Each save becomes a commit, and the site updates about a minute later.

How do I get a token?
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Resource owner: the account or organisation that owns the repository. Repository access: Only select repositories → this repository.
  3. Permissions → Repository → Contents: Read and write. Nothing else is needed.
  4. Pick an expiry, generate, and paste the token here.

The token stays in this browser and is only sent to api.github.com. Without “Remember”, it is forgotten when you close the tab.
