Analisis yang tersedia

Koordinat dibaca sebagai WGS 84 (UTM dan Web Mercator diubah otomatis). Luas dan panjang dihitung pada elipsoid WGS 84, jadi hasilnya dalam meter dan hektare sebenarnya, bukan derajat.

Luas, keliling & panjangSemuaLapisan + tabelMenambah kolom luas_ha dan kelilingkm (poligon), panjang_km (garis), atau bujur/lintang (titik). Luas dihitung pada elipsoid (proyeksi luas-sama), jarak dengan rumus Vincenty.

Pernyataan privasi data

GeoSAI tidak menyimpan data yang Anda analisis. Kami membangun alat ini sehingga file Anda memang tidak pernah sampai ke kami:

  • Tidak diunggah.File dibaca dan dianalisis oleh browser di perangkat Anda. Isinya tidak dikirim ke server GeoSAI maupun pihak ketiga; situs ini tidak punya server pengolah data.
  • Tidak disimpan.GeoSAI tidak menyimpan, menyalin, melihat, atau membagikan file Anda maupun hasil analisisnya. Data hanya ada di memori tab ini dan hilang saat Anda menekan Hapus data dari memori browser, memuat ulang, atau menutup halaman.
  • Peta dasar dari pihak ketiga.Ubin peta dasar dimuat dari OpenStreetMap atau Esri, seperti di peta web mana pun. Server mereka bisa melihat bagian peta yang sedang ditampilkan, tetapi tidak menerima file Anda. Pilih Tanpa peta dasar (tombol lapisan di pojok peta) bila lokasi pun ingin dirahasiakan.
  • Hanya statistik anonim.Kami menghitung kunjungan halaman dan berapa kali setiap jenis analisis dipakai dengan GoatCounter, tanpa cookie dan tanpa data pribadi. Nama file, isi file, koordinat, dan atribut tidak pernah dicatat.
  • Bisa Anda periksa sendiri.Halaman ini memasang aturan keamanan browser (Content Security Policy) yang hanya mengizinkan koneksi data ke situs ini dan penghitung statistik di atas.

Anda tetap bertanggung jawab atas hak penggunaan data yang Anda analisis dan atas file hasil yang tersimpan di perangkat Anda.

Batas dan ketelitian

Di perangkat ini file boleh hingga … (batas memori browser, sama seperti di Konversi data).

  • LuasElipsoid WGS 84
  • Jarak & panjangVincenty, ±1 mm
  • Buffer±0,3 % dari jarak
  • PetaHingga 50.000 fitur

Buffer, clip, erase, intersect, dan dissolve pada poligon yang sangat rinci (puluhan ribu titik sudut) bisa memakan waktu beberapa detik hingga menit. Poligon yang tidak valid (bersilangan sendiri) bisa gagal diproses; perbaiki dulu di QGIS (Vector → Geometry Tools → Fix Geometries).

Statistik spasial di sini adalah alat eksplorasi. Untuk laporan resmi, uji tuntas, atau analisis lanjutan (regresi spasial, interpolasi, analisis citra), konsultasikan dengan kami.

Butuh analisis yang lebih dalam?

Kami menganalisis tumpang tindih perizinan, perubahan tutupan lahan, kesesuaian lahan, dan risiko lokasi, lalu menyajikannya sebagai peta dan laporan siap pakai.
