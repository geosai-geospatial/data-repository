Pernyataan privasi data

GeoSAI tidak menyimpan data yang Anda buka. Kami membangun alat ini sehingga file Anda memang tidak pernah sampai ke kami:

  • Tidak diunggah.File dibaca dan diwarnai oleh browser di perangkat Anda. Isinya tidak dikirim ke server GeoSAI maupun pihak ketiga; situs ini tidak punya server pengolah data.
  • Tidak disimpan.Data hanya ada di memori tab ini dan hilang saat Anda menekan Hapus data dari memori browser, memuat ulang, atau menutup halaman.
  • Peta dasar dari pihak ketiga.Ubin peta dasar dimuat dari OpenStreetMap atau Esri, seperti di peta web mana pun. Server mereka bisa melihat bagian peta yang sedang ditampilkan, tetapi tidak menerima file Anda. Pilih Tanpa peta dasar bila lokasi pun ingin dirahasiakan.
  • Hanya statistik anonim.Kami menghitung kunjungan halaman dan berapa kali alat ini dipakai dengan GoatCounter, tanpa cookie dan tanpa data pribadi. Nama file, isi file, dan lokasinya tidak pernah dicatat.
  • Bisa Anda periksa sendiri.Halaman ini memasang aturan keamanan browser (Content Security Policy) yang hanya mengizinkan koneksi data ke situs ini dan penghitung statistik di atas.

File yang bisa dibuka

  • FormatGeoTIFF, COG, BigTIFF
  • KompresiTanpa, LZW, Deflate, PackBits, JPEG, WebP
  • Tipe nilai8–64 bit, bulat atau desimal
  • ProyeksiWGS 84, Web Mercator, UTM, TM-3

UTM boleh WGS 84 atau DGN95. Nilai NoData, band alfa, nama band, dan palet warna dari file ikut dibaca.

File besar tetap bisa dibuka. Browser hanya membaca bagian file yang diperlukan, dan tampilan memakai resolusi yang diperkecil hingga maks. 2.048 piksel per sisi (lebih kecil lagi bila band-nya banyak). File yang punya overview (misalnya COG) terbuka jauh lebih cepat.

Belum didukung: kompresi ZSTD, LERC, dan JPEG 2000, serta proyeksi lain (mis. Lambert, Albers). Simpan ulang di QGIS (Export → Save As, CRS EPSG:4326, kompresi DEFLATE) atau dengan gdalwarp -t_srs EPSG:4326 -co COMPRESS=DEFLATE.
